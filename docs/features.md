# Features – Cab Booking System

## User Features

- User registration and login
- Enter pickup and drop location
- View available cabs
- Book a cab
- Real-time ride tracking
- Secure payment options
- View booking history

---

## Driver Features

- Driver login and authentication
- Receive ride requests
- Accept or reject ride bookings
- View passenger pickup location
- Start and complete rides
- Update ride status

---

## Admin Features

- Manage users and drivers
- Monitor ride bookings
- Manage system data
- View ride reports and analytics
- Handle complaints or issues
