# User Flow – Cab Booking System

## User Booking Flow

![User Flow](../images/user-flow.png)

### Explanation

1. User opens the application.
2. User registers or logs into the system.
3. User enters pickup and destination location.
4. System shows available cabs.
5. User selects a cab and confirms the booking.
6. The system assigns a driver.
7. The ride begins and the user can track the ride.
8. After reaching the destination, the ride is completed.
9. User makes payment and the booking is recorded.
