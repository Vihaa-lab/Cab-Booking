# Roles and Responsibilities – Cab Booking System

## User

The user is the passenger who books the cab through the application.

Responsibilities:
- Register and login into the system
- Enter pickup and drop location
- Book a ride
- Track ride status
- Make payment after ride completion
- View ride history

---

## Driver

The driver provides the cab service and completes the rides assigned.

Responsibilities:
- Accept ride requests
- Navigate to passenger pickup location
- Start and complete rides
- Update ride status in the system
- View ride details and history

---

## Admin

The admin manages the overall system and ensures smooth operation.

Responsibilities:
- Manage users and drivers
- Monitor rides and bookings
- Handle complaints and issues
- Maintain system data and records
